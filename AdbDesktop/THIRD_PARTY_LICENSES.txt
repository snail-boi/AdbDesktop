Android Debug Bridge (adb.exe, AdbWinApi.dll, AdbWinUsbApi.dll)
Part of the Android SDK Platform Tools.
Copyright (C) The Android Open Source Project
Licensed under the Apache License, Version 2.0.
https://developer.android.com/tools/releases/platform-tools
https://www.apache.org/licenses/LICENSE-2.0

NOTE: this must stay byte-identical to the adb.exe shipped by Android Music
Presence Link and Android Shortcut Maker. All three applications share a single
adb *server* process, and a version mismatch causes adb to kill and restart the
server, which makes every one of them drop its connection.

Bundled version: 1.0.41 (37.0.0-14910828)

================================================================================
libwebp (libwebp.dll, libsharpyuv.dll)
Copyright (c) 2010, Google Inc. All rights reserved.
Licensed under the BSD 3-Clause License.
https://chromium.googlesource.com/webm/libwebp

PROVENANCE NOTE: the official libwebp Windows release
(libwebp-<ver>-windows-x64.zip) ships only the command-line tools and a static
libwebp.lib -- it contains no DLL. The binaries bundled here are prebuilt x64
DLLs (libwebp.dll 550,160 bytes; libsharpyuv.dll 61,200 bytes) sourced from a
local install rather than from that archive, so their exact upstream version is
unrecorded. They should be replaced with a DLL built from a known libwebp tag
before any public release.

libwebp.dll additionally imports VCRUNTIME140.dll, so end users need the
Microsoft Visual C++ 2015-2022 Redistributable. If that turns out to be a
problem, building libwebp with /MT would remove the dependency.

Only three entry points are used: WebPGetInfo, WebPDecodeBGRA and WebPFree.
